🎵 YouTube Stream Resolver API

Vercel serverless function for extracting YouTube stream URLs (cookie-free).

Endpoint

GET /api/youtube/resolve?url=

Parameters

  • url (required) - YouTube URL or 11-character video ID

Example

/api/youtube/resolve?url=https://www.youtube.com/watch?v=PTjOWm3p5XM

Success Response

{
  "status": "ok",
  "stream_url": "https://rr5---sn-xxx.googlevideo.com/videoplayback?...",
  "title": "Video Title",
  "duration": 199,
  "video_id": "PTjOWm3p5XM",
  "format": {
    "itag": 140,
    "mime_type": "audio/mp4; codecs=\"mp4a.40.2\"",
    "bitrate": 128000,
    "quality": "AUDIO_QUALITY_MEDIUM",
    "container": "mp4"
  }
}

Error Response

{
  "status": "error",
  "error": "Sign in to confirm you're not a bot",
  "bot_wall": true
}
